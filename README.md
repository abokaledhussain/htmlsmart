# HtmlSmart Web

نسخة المتصفح من تطبيق HtmlSmart لإدارة صفحات HTML. تعمل بالكامل داخل المتصفح بدون خادم.

## التشغيل

افتح ملف `index.html` في متصفح حديث، أو ارفع المجلد على أي استضافة ثابتة.

## المزايا

- تصفح الصفحات والمجلدات، مع البحث بالاسم.
- النقر على أي أيقونة يفتحها.
- تغيير عدد الأعمدة من زر الشريط العلوي، بنافذة منبثقة مباشرة.
- ملء الشاشة.

هذه النسخة للعرض فقط: لا يمكن فيها إضافة صفحات أو تعديلها أو حذفها، ولا تُنشأ فيها مجلدات.

## النسخة الاحتياطية

إذا وُضع ملف `backup.zip` بجانب `index.html` (بصيغة تطبيق الأندرويد)، تُستعاد الصفحات منه تلقائياً عند فتح الصفحة، وتُعاد الاستعادة عند تغيير الملف.

## غير متاح في المتصفح

المزامنة بين الأجهزة، والمتصفح الافتراضي، وقفل التطبيق بـ PIN أو البصمة. هذه الميزات متوفرة في تطبيقات الأندرويد وWindows وmacOS وiOS.

## البنية

- `index.html` الهيكل والنوافذ.
- `css/style.css` التنسيق والوضع الفاتح والداكن.
- `js/app.js` منطق الواجهة والصفحات والإعدادات.
- `js/storage.js` الحفظ في IndexedDB.
- `js/backup.js` النسخ والاستعادة (يعتمد JSZip من CDN لملفات ZIP).
